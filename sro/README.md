## Описание проекта
Это простая, легко понимаемая и готовая к сдаче версия проекта по **теме №9**. Программа написана на чистом Python с использованием встроенной базы данных SQLite и демонстрирует ключевые парадигмы программирования:
- **База данных (`sqlite3`):** сохранение и автоматическое заполнение данных.
- **ООП (Лекция 5):** класс `Task` для описания сущностей.
- **Функциональный подход (Лекция 3, 7):** чистая функция расчета прогресса `calculate_progress`.
- **Точка входа (Лекция 4):** понятная структура запуска.

## Инструкция по запуску на Windows

1. Убедитесь, что у вас установлен **Python** (при установке была поставлена галочка *Add Python to PATH*).
2. Распакуйте архив в удобное место (например, на рабочий стол в папку `simple_topic_9`).
3. Откройте командную строку (**cmd**) в папке с проектом:
   - Нажмите `Win + R`, введите `cmd` и нажмите Enter.
   - Перейдите в папку проекта командой (укажите свой путь):
     ```cmd
     cd /d C:\Users\Student\Downloads\simple_topic_9
     ```
4. Запустите программу:
   ```cmd
   python app.py
   ```
