## Описание проекта
В данный проект интегрированы **все студенты из предоставленных официальных списков группы** (22 студента из двух ведомостей). Каждый студент получил уникальный `id`, тему индивидуального учебного проекта, количество выполненных/всех задач и текущий статус.

## Инструкция по запуску на Windows
1. Откройте командную строку (`cmd`).
2. Перейдите в папку проекта:
   ```cmd
   cd /d C:\Users\Student\Downloads\sro
   ```
3. Запустите программу:
   ```cmd
   python app.py
   ```
